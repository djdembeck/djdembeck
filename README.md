### [AudiobookDB](https://audiobookdb.org)

**A community-maintained catalog for audiobooks, with books and their releases kept distinct.** AudiobookDB is in beta, with editorial review, a developer API, and room for contributors. It’s the product I’m spending much of my time on: building a useful home for audiobook metadata and a community that can help improve it.

### How I build

AI agents have made it possible to move quickly, but speed only matters when the result is right. I give agents clear direction, then apply human judgment to the design and tradeoffs, review what they produce, and verify the behavior. AI can generate an interface; it doesn’t give it taste or make it work on a phone.

I’m a maintainer on [AxonHub](https://github.com/looplj/axonhub), an open-source LLM gateway. Recent public work includes a Go and SvelteKit rewrite of [Bragibooks](https://github.com/djdembeck/bragibooks), improvements to my [GPU-aware LLM router](https://github.com/djdembeck/llm-router-go), and an **open** dashboard redesign for [Annalist](https://github.com/djdembeck/annalist). I use [oh-my-pi](https://github.com/djdembeck/oh-my-pi) to direct coding agents and [Mira](https://github.com/djdembeck/mira) for AI code review. I use self-hosted Forgejo daily and have contributed Forgejo support to Mira, robomp, and Kodus.
