## Hi, I’m David.

I’m a software engineer at [Laxamentum Technologies](https://laxamentum.tech), building software that fixes the things other people have learned to work around.

### [AudiobookDB](https://audiobookdb.org)

**A community-maintained catalog for audiobooks, with books and their releases kept distinct.** AudiobookDB is in public beta, with editorial review, a developer API, and room for contributors. I’m building it as a shared home for audiobook metadata that people can help improve.

### How I build

I direct AI agents when building software and check their work against what I intended, including trying interfaces on a phone.

I’m a maintainer on [AxonHub](https://github.com/looplj/axonhub), an open-source LLM gateway. Recent public work includes a Go and SvelteKit rewrite of [Bragibooks](https://github.com/djdembeck/bragibooks), improvements to my [GPU-aware LLM router](https://github.com/djdembeck/llm-router-go), and a dashboard redesign for [Annalist](https://github.com/djdembeck/annalist) merged into the development branch. I use [oh-my-pi](https://github.com/djdembeck/oh-my-pi) to direct coding agents and [Mira](https://github.com/djdembeck/mira) for AI code review. I use self-hosted Forgejo daily and have contributed Forgejo support to Mira, robomp, and Kodus.
